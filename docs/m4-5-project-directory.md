# M4-5：项目目录策略

`resolveOpenCodeDirectory` 只读解析原始项目路径，返回源路径、目标目录、策略、
存在性与稳定拒绝原因，供 dry-run 和实际迁移共用。

- 默认保留同平台路径，不创建不存在的目录。
- 显式 path map 按最长目录前缀匹配，严格使用路径组件边界。
- 显式 fallback 在原路径/映射路径不可用时生效，也支持源项目路径缺失。
- Windows drive、大小写、UNC 使用 Windows 语义，支持跨平台映射。
- 拒绝相对路径、drive-relative、设备路径、NUL 与冲突映射。
- POSIX 文件名中的反斜杠不会在跨平台时被误解释为 Windows 路径分隔符。
- 返回对象含路径，只用于内部计划；CLI/日志需要使用既有脱敏边界投影。
