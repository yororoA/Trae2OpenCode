Trae2OpenCode

把 TRAE 会话，完整带到 OpenCode。

一条命令迁移消息、推理与工具调用。自动识别 OpenCode v1/v2 协议，支持中断续跑，并在写入后逐项回读核验。

在 GitHub 获取 查看使用方式
$ npm run migrate:local
1 条命令完成迁移
macOS + Windows 本机 TRAE 来源读取
v1 + v2 双协议目标适配
Readback 写入后逐项核验

01

不是复制粘贴

迁移的是可以继续工作的上下文

TRAE 中的原始会话

消息、推理、命令、状态与时间关系相互交织。

IR 规范化 · 脱敏 · 映射
OpenCode 原生时间线

保持顺序和语义，并对目标结果逐项回读。

02

交互演示

选择会话，其余交给迁移器

无需寻找 workbench ID 或 session ID。多选、覆盖保护、续跑与核验都在同一流程中完成。

选择会话后开始迁移。

03

迁移不靠运气

每一步都有明确证据

01

保留过程

Assistant 过程文本、reasoning 与工具调用按原顺序进入 OpenCode 原生时间线。

02

默认保护

自动剥离已识别凭据；无法证明归属的目标、未知版本与不完整写入都会停止。

03

可以续跑

Manifest 记录每个阶段。中断后从可靠检查点继续，不重复导入已验证内容。

Fail closed

看不懂的数据，不猜。
无法验证的目标，不写。

稳定身份与所有权标记
Schema、快照与完整 hash
导入后逐消息回读对账

04

快速开始

准备好两个应用，然后运行一条命令

  1. 1

    安装依赖

    克隆仓库，并使用 Node.js 18.18 或更高版本。

  2. 2

    启动 TRAE 调试端口

    在 macOS 或 Windows 上用调试参数启动 TRAE，并打开目标项目窗口。

  3. 3

    运行迁移

    按列表选择会话，等待回读核验完成。

Terminal 
"/Applications/Trae CN.app/Contents/MacOS/Electron" \
  --remote-debugging-address=127.0.0.1 \
  --remote-debugging-port=9222

npm run migrate:local
